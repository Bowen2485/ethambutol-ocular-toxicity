# GeneCards 手动检索清单

共 66 个基因：33 个 hub（按网络连接度降序）+ 33 个对照。

**每个基因只需看一件事**：`Disorders` 分区里有没有眼病（视网膜、视神经、黄斑、青光眼、葡萄膜炎、白内障、角膜等）。

**记录格式**（填回 `results/genecards_search_list.csv`）：

| 列 | 填法 |
|---|---|
| `genecards_eye_related` | `yes` / `no` |
| `genecards_diseases` | 眼病名称，多个用 `;` 分隔 |
| `genecards_score` | 相关性评分（可选） |

**若你懒得填表**：直接把看到的内容贴给我（任意格式），我来整理。

## 已有的 DisGeNET 结果（供你对照）

我已完成 DisGeNET 那次检验，结果是 **hub 18/33（55%）vs 对照 4/33（12%）**，
Fisher P = 2.6×10⁻⁴。**阳性对照通过**：OPA1（13 种眼病）、DNM1L、MFN2 均被
检出为视神经萎缩相关。

**GeneCards 这一遍的目的是独立复现**。所以：

- **不要参考我的结果去填** —— 若你按 DisGeNET 的预期填，就不构成独立检验
- **按页面上实际显示的填** —— 包括与我结果不一致的情况
- **若某个基因在 GeneCards 上有眼病而 DisGeNET 上没有（或反之），照实记录**
