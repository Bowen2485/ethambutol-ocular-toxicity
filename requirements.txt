# Dependency record for the ethambutol ocular-toxicity analysis.
#
# Why this file exists
#     The manuscript's software paragraph names the libraries but no lock file was ever kept, so
#     a reader could not reproduce the run.  Every version below was read from the interpreter
#     that actually holds it rather than transcribed from documentation:
#         * the analysis environment, C:\Python314\python.exe (3.14.8), queried with
#           importlib.metadata
#         * the docking packages, read from the project's own .piptarget/*.dist-info directories
#         * the molecular-dynamics environment, taken from docs/MD环境踩坑记录_实测.md, which
#           records what was measured in WSL (Python 3.12.15, conda env ~/miniconda3/envs/md)
#
# Two environments, not one
#     The pharmacovigilance, network, docking and Mendelian randomisation analyses run on
#     Windows under Python 3.14.  The all-atom molecular dynamics needs OpenMM and AmberTools and
#     runs separately in WSL under Python 3.12.  They are kept apart below because they cannot be
#     merged: the MD stack pins Python 3.12 and a development build of OpenMM.
